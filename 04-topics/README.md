# 选题推进

这里保存可以接受审查的研究问题。方向名称只能作为起点，不能代替问题本身。

先在[候选清单](candidates.md)分配编号，再复制[选题卡](../templates/topic-card.md)到 `cards/`。在卡片中说明研究对象、问题、已有证据、设计与可行性，并链接相应文献。

## 进入导师讨论前

1. 能用一句话提出具体问题，并说明现有研究已经回答到哪里。
2. 核查近似研究、相关综述和不同结论的证据，解释还需要研究什么。
3. 说明能接触什么对象和资料，工具从哪里来，预计需要多少时间。
4. 说明设计实际能支持什么结论，以及最难排除的替代解释。

新颖的主题措辞不能代替研究价值。模型复杂不能代替设计质量。若关键资料无法取得，优先缩小或改变问题。

保留与放弃的理由同时写入[决定记录](../00-planning/decisions.md)。正式确定后，将研究方案放入[论文目录](../05-thesis/README.md)，原选题卡继续保留。

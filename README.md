# cecelia-s-master-path

小学教育语文方向硕士学习与研究记录。

本仓库用于保存文献阅读、课程作业、研究方法学习和选题推进中的可核查记录。目标是让研究问题有来源，让方法选择有理由，让写作中的结论能够回到原文或实际材料。

## 从这里开始

1. 打开[当前任务](00-planning/README.md)，本周只保留少量可以完成的事项。
2. 阅读论文时先登记[文献索引](01-literature/index.md)，再复制[精读模板](templates/reading-note.md)填写笔记。
3. 课程要求、作业草稿和提交材料放进同一课程项目，入口见[课程作业](02-coursework/README.md)。
4. 遇到不理解的方法时，复制[方法笔记模板](templates/method-note.md)，结合一篇实际论文整理。
5. 出现选题想法时，填写[选题卡](templates/topic-card.md)，先检查问题、证据和实施条件。

## 日常维护

- 读一篇论文，更新一条索引和一份笔记。没有核对全文时，保留“未读全文”状态。
- 完成一项作业，补上课程要求、本人贡献、材料来源和实际提交版本。
- 学一个方法，说明它回答什么问题、需要什么数据、依赖什么条件。
- 每周整理一次任务和记录。未完成的事项写明原因，不用阅读数量代替研究进展。
- 每月依据周记录起草月报。只有检索到的论文不能写成“已精读”，只有计划不能写成“已完成”。

## 引用和文件边界

论文书目信息以期刊官网、DOI 页面或正式原文为准。精读笔记区分作者的发现、作者的解释和自己的判断。引文标明页码，必要时同时写明印刷页码和 PDF 页码。AI 辅助整理的内容经过本人核查后才能进入正式稿。

这是公开仓库。默认提交本人编写并适合公开的笔记、摘要、分析说明和可分享成果。受版权限制的全文、学生个人信息、访谈录音及其他非公开材料保存在仓库外。临时本地资料可放入被忽略的 `_local/`，但 `.gitignore` 不能保护已经提交的文件。保密材料应使用有访问控制的独立存储。

## 第一次使用

先迁入一份已经完成的阅读笔记，再完善一项当前课程作业，最后整理一份方法笔记。把这三份记录中的实际问题写进选题卡。其余目录随工作自然增加，不必一次填满。

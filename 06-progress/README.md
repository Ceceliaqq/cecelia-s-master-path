# 进度记录

复制[周记录模板](../templates/weekly-review.md)到 `weekly/`。复制[月报模板](../templates/monthly-report.md)到 `monthly/`。模板只提供格式，不自动生成完成事项。

周记录写实际完成、相应文件、理解变化、未解决问题和下周安排。已精读、已练习、已写作和只检索到的内容分开记录。

月报依据当月周记录及产出文件整理，保留事实来源。信息不足写“待补充”。发给导师的版本由本人审核，本仓库不自动发送。

导师反馈或组内讨论涉及他人时，只记录研究问题和本人后续修改，避免公开姓名、联系方式与未获同意的讨论内容。

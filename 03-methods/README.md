# 研究方法学习

方法学习以具体研究问题为起点。先判断数据怎样产生、分析单位是什么，再看模型和软件。笔记复制[方法模板](../templates/method-note.md)到 `notes/`，练习放入 `exercises/`。

## 待整理的学习主题

以下来自近期学习范围，统一标为“待整理”，不代表已掌握。

| 主题 | 要能回答的问题 | 状态 | 笔记入口 |
| --- | --- | --- | --- |
| 描述统计、效应量与不确定性 | 分数差异有多大，估计有多不确定？ | 待整理 | 待添加 |
| 实验与准实验 | 比较组是否支持所声称的教学效果？ | 待整理 | 待添加 |
| 重复测量与混合效应模型 | 时间、学生、班级和材料的依赖怎样处理？ | 待整理 | 待添加 |
| 中介分析 | 路径估计需要哪些条件，何时只能解释为关联？ | 待整理 | 待添加 |
| 结构方程模型 | 测量模型和结构模型分别检验什么？ | 待整理 | 待添加 |
| 课堂观察与编码 | 行为如何定义，编码者怎样独立判断并检验一致性？ | 待整理 | 待添加 |
| 访谈与质性分析 | 研究对象如何选择，解释如何获得材料支持？ | 待整理 | 待添加 |
| 教材内容分析 | 分析单位、类别和判断规则如何确定？ | 待整理 | 待添加 |

每份笔记至少关联一个真实研究例子。尚未实际使用的软件、模型或练习不要记为“已完成”。新增方法时检查是否与现有笔记重复。

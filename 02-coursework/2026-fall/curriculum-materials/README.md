# 课程与教材研究汇报

当前主题为“统编小学语文教材中华民族共同体意识教育的内容呈现与育人价值分析”，以一、二年级教材为例。最终表述以小组确认版本为准。

本人当前负责中华优秀传统文化选文的育人价值分析。教材版本、截止日期、最终分工及现有稿件待迁入，不能仅凭目录创建判断任务已经完成。

## 分析记录的基本要求

每项判断列出具体课文、原文或活动依据及页码，并说明为什么可以这样解释。选文包含传统文化内容，不足以单独证明学生已经形成相应认同。只有教材材料时，结论限于内容呈现、可能的育人价值和教学条件。

需要区分教材内容、研究者的价值解释和学生实际学习效果。最后一类需要学生或课堂资料，不能用文本分析替代。

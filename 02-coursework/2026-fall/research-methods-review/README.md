# 教育研究方法课程综述

## 任务与范围

暂定题目为《小学语文阅读策略教学研究述评》。当前作为课程文献综述推进，具体题目随检索结果调整。

现有要求是正文不少于 5000 字，参考文献至少 15 篇，需要总结已有观点、评价贡献与不足，并提出研究展望。教师原始要求、准确截止日期和格式要求待迁入核对。投稿是后续目标，不记录为既定成果。

## 优先要回答的问题

1. 研究中的阅读策略教学具体指什么，和策略使用测量如何区分？
2. 研究针对哪些学生、文本和教学情境，使用什么教学安排与比较条件？
3. 哪些证据支持教学效果，哪些证据只能说明关联或课堂实施情况？
4. 研究分歧是否与测量、教师实施、样本或设计差异有关？

这些问题用于指导检索和综合，不提前确定综述会得出什么结论。

## 材料与产出

- 文献统一登记在[文献索引](../../../01-literature/index.md)，不要复制第二份完整索引。
- 检索过程记入[检索记录](../../../01-literature/search-log.md)，标明关联本项目。
- 先形成主题综合，再按问题组织正文，避免逐篇摘要堆叠。
- 写作开始后建立 `drafts/`，实际提交时再建立 `deliverables/`。

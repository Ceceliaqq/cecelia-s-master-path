# 硕士论文

这是正式研究的预留入口，目前没有填入开题材料。课程综述、教材汇报和方法学习保留在各自目录，通过链接供论文研究使用。

研究问题与实施条件确认后，按实际需要增加以下目录。

| 目录 | 用途 |
| --- | --- |
| `proposal/` | 问题、文献依据、设计、资料计划及修订理由 |
| `instruments/` | 可公开的工具、来源、使用条件、操作与编码说明 |
| `analysis/` | 可公开的分析代码、数据说明、输出与解释 |
| `writing/` | 正文各部分、引用、修订记录 |
| `defense/` | 答辩提纲、问题清单和修改说明 |

涉及真实研究对象的材料获取与使用条件应在实施前确认。原始资料、身份对应表和同意材料不放入公开仓库。研究方案写明分析单位、测量安排、缺失资料处理及解释边界，避免看到结果后再倒推研究问题。

# 文献阅读

先在[文献索引](index.md)分配编号，再复制[精读模板](../templates/reading-note.md)到 `notes/`。围绕一个问题比较多篇文献时，复制[主题综合模板](../templates/synthesis-note.md)到 `syntheses/`。

## 阅读范围

覆盖小学语文课程与教材、阅读、写作、口语交际、识字写字、教师教学及相关教育问题。阅读策略教学是当前课程综述的工作主题，不作为所有阅读的固定范围。

## 两种状态分别记录

| 维度 | 可用状态 |
| --- | --- |
| 来源核验 | 待核验、书目信息已核、全文信息已核 |
| 阅读进度 | 待读、读摘要、初读、精读待补、精读完成 |

正式研究是否支持某个结论，需要在笔记中另行判断。来源正规不代表设计没有限制，方法复杂也不代表结论更强。

检索过程记入[检索记录](search-log.md)。可以用 Zotero 等文献管理软件管理全文和引用，本仓库保存索引与自己的判断，不要求手工复制整个文献库。
